# Student Performance Prediction Using Machine Learning

## Project Overview
This beginner-level project predicts student academic performance using study hours, attendance, and previous marks.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## Features
- Student data analysis
- Data visualisation
- Linear Regression model
- Model evaluation using MAE and R-squared
- Prediction of marks for a new student

## Dataset
The initial version uses a small illustrative dataset created for learning purposes.

## How to Run
Open the Jupyter notebook in Google Colab and run the cells in order.

## Future Improvements
Use a real-world student dataset and compare machine learning algorithms.
